# Decisions

Architecture decision records. Each one states the context, the decision, the evidence and the consequences. To change a decision, add a new record that supersedes the old one.

| [0035](./0035-imports-become-one-captured-tree.md)       | HTML paste, live URL capture and Figma paste become one captured tree; deterministic code writes TSX with token classes, AI only tidies                       | proposed                                  |
